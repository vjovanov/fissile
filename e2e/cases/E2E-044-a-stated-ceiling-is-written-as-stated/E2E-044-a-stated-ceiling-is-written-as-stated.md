# E2E-044-a-stated-ceiling-is-written-as-stated: a `--max` is the ceiling, and the step is only named

The entry accepts 20 lines of a 9-line file — loose by any measure — and the
caller states 10. The registry gets 10, not the 12 the 4-line step would have
chosen: a typed number is already a decision, and rounding it would replace the
caller's number with one nobody chose (§FS-008-exception-retune.1,
§DF-010-stated-ceilings-are-exact.1).

The result still names the step's next multiple, so the round number the
measured form would have written is one line away if that is what the caller
wanted (§FS-008-exception-retune.3). Because the stated value moves by exactly
what was stated, this is also how a ceiling comes down by less than one step
(§FS-008-exception-retune.2).
