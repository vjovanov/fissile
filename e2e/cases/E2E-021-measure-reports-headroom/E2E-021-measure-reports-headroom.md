# E2E-021-measure-reports-headroom: measure reports the count and the distance to what binds

`fissile measure` answers what `check` will not: the file's measured size in the
arithmetic the budgets use, the limits that apply, and the distance to whichever
threshold binds first (§FS-007-measure.2). Here the file stands past its hard
limit, and the command still exits zero — measuring is inspection, and a file
over a limit is an answer rather than a verdict (§FS-007-measure.1).
