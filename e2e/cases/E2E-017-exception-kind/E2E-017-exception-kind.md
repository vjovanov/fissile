# E2E-017-exception-kind: a deferred exception cannot be open-ended

An exception's kind decides what its reason must establish and what `until` may
say (§FS-003-exceptions.2.1). `deferred` means no constraint makes the split
illegal — a boundary is simply missing — so the entry has to name what retires
it. Accepting `--until indefinite` there would let ordinary debt be recorded as
permanent without anyone claiming it is, which is the confusion the field exists
to end (§DF-004-exception-kind).

The command refuses before touching the registry, and the diagnostic names the
other kind: if the file genuinely can never be split, the entry is `structural`,
not deferred-forever (§FS-005-exception-add.4).
