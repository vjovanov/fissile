# E2E-067-a-ceiling-on-the-step-multiple-names-the-stated-form: the advice is a call the command performs

`audit` never names a remedy the command would decline (§FS-004-check-audit.2).
A ceiling with no headroom is normally moved by the measured form of
`fissile exception retune`, which rounds the measurement up to the bump step
(§FS-003-exceptions.7) — but where the measurement is already a multiple of that
step, rounding it up returns the number the entry already records, and `retune`
reports that it changed nothing.

So this line does not say `retune to 12`. It names the stated form and the
step's next multiple strictly above the ceiling, `retune with --max 16 --unit
lines`, which is the smallest round number that grants any headroom at all.
