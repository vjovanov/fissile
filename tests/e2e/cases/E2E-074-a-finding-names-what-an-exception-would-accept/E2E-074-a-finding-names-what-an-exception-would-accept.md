# E2E-074-a-finding-names-what-an-exception-would-accept: the finding names the ceiling a plain exception writes

A file over its hard limit is reported with the ceiling a `fissile exception
add` carrying no `--max` would record for it — the measurement rounded up to the
unit's `[exceptions.bump]` step — beside the measurement and the budget it
crossed (§FS-004-check-audit.1). Without it the only number on screen is the
measurement, and a caller who copies that into `--max` records a ceiling with no
headroom (§DF-010-stated-ceilings-are-exact.1).

The step here is the configured one rather than the 100-line default
(§FS-001-config.5), so a 46-line file reports 50: the number is read from the
tree's own `[exceptions.bump]`, not assumed.
