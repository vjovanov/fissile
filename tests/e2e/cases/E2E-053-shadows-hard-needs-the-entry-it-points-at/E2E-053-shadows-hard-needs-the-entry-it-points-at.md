# E2E-053-shadows-hard-needs-the-entry-it-points-at: a shadow of nothing is refused

`--shadows-hard` takes its kind, reason, and retirement condition from the hard
entry at the same address, so an address no hard entry answers has nothing to
give it (§FS-005-exception-add.1.1). The command refuses before writing.

The refusal names the registry it looked in, because that is the file a reader
has to open (§DF-005-exception-identity), and it names both ways forward: record
the hard acceptance the twin would shadow, or state this entry's own three
flags. Recording the shadow of a decision nobody made would leave a registry
that no longer loads (§FS-003-exceptions.2.3), so the check is here rather than
at the next `check`.
