# E2E-039-the-offered-soft-route-runs: the refusal's own command succeeds

The `--severity hard` gate refuses off a terminal and names the route an agent
can take instead (§FS-005-exception-add.4). That route is an instruction at the
error site (§DF-007-instructions-at-the-error-site.2), so it has to run as
printed — a caller who follows it and lands on a second refusal has been told
nothing, and is left with hand-edited registry TOML.

This case runs the exact command `E2E-034-hard-exception-needs-a-human` asserts
the refusal prints, against the same repository, and the entry lands. The
`--kind structural` the caller claimed survives, so `until` is `indefinite`
rather than a retirement condition invented for a constraint that never retires
(§DF-004-exception-kind).
