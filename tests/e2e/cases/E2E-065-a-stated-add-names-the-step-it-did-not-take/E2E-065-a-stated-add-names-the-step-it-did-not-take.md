# E2E-065-a-stated-add-names-the-step-it-did-not-take: `add --max` names the round number one step up

The caller states 10 lines for a 9-line file, and the registry records exactly
10: a typed number is the decision, and rounding it would replace it with one
nobody chose (§FS-005-exception-add.2).

A ceiling that close to the measurement has almost no headroom, so the result
names the step's next multiple — the 12 the measured form would have written —
as the round number available for the asking, applied to nothing
(§FS-005-exception-add.2). Without it, `add` wrote the pinned ceiling in
silence while `exception retune` named the same alternative for the same
number (§FS-008-exception-retune.3).
