# E2E-049-audit-names-the-stated-form-on-the-hard-limit: audit does not recommend a retune the command would refuse

`audit --stale-exceptions` names, for each loose entry, the ceiling
`fissile exception retune` would write (§FS-003-exceptions.7,
§FS-004-check-audit.2). For a soft entry whose step lands on the hard limit
that value is one `retune` refuses (§DF-010-stated-ceilings-are-exact.2), and a
report that recommended it would send the reader into the refusal.

So the line names the stated form and the range that keeps the ceiling under
the limit — `retune with --max <N> --unit lines, 5 <= N < 8` — and the JSON
record's `retune_to` is `null` for the same entry.
